# Reporting a security issue

Use GitHub's private vulnerability reporting for a suspected security issue in this repository when available. Do not include credentials, private prompts, or real terminal captures in a public issue. If private reporting is unavailable, open an issue requesting a private contact without disclosing exploit details.

The provided local server binds to loopback, validates Host and Origin, rejects cross-site API access, and requires same-origin JSON POSTs with a custom header. Real tmux input is disabled by default, restricted by the selected session prefix, and validated again in the adapter.

Grid itself is a client presentation component. A production host must enforce its own authentication and per-session authorization on its server, including any separately mounted terminal renderer. Client-side hidden or disabled controls are not an authorization boundary.

Agent Grid v0.1.x is the currently supported line.
