# @karnafkatom/agent-grid

The reusable library for [Agent Grid](https://github.com/Karnaf0katom/agent-grid). Browser-native web component, JavaScript core, TypeScript declarations, and adapter contract. No runtime dependencies or build step.

See the [integration guide](https://github.com/Karnaf0katom/agent-grid/blob/main/apps/agent-grid/docs/integrating.md) and [license guide](https://github.com/Karnaf0katom/agent-grid/blob/main/apps/agent-grid/docs/licensing.md).
